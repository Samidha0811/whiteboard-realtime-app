# 🎨 Real-Time Whiteboard Game

A multiplayer drawing and guessing game like Skribbl.io.

## 🚀 Features
- Real-time drawing (WebSockets)
- Multiplayer rooms
- Chat & guessing system
- Turn-based gameplay

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: Spring Boot
- WebSocket for real-time communication

## ▶️ How to Run the code

### Backend
cd backend
mvn spring-boot:run

### Frontend
cd frontend
npm install
npm start
